# Макет 5.0: логика и устройство

5.0 — основная версия макета кабинета учителя. По структуре ориентируемся на EdVibe,
визуал свой (палитра 4.7/4.8, карточки 4.4).

## Разделы и порядок

| Раздел | Путь | Что там |
|--------|------|---------|
| Главная | `/` | 6 карточек-входов, уроки на сегодня, работы на проверку |
| Классы | `/classes` | Индивидуальные и групповые классы, создание класса |
| Ученики | `/students` | Список/плитка, поиск, фильтр, приглашение, плашка про непроверенные домашки |
| Курсы | `/courses` → `/courses/:id` → урок | Учебные материалы (у EdVibe — «Материалы») |
| Расписание | `/schedule` | Неделя 8:00–22:00, уроки классов |
| Домашки | `/homework?tab=review\|assigned\|checked` | Проверка, заданные, проверенные; «Задать домашку» |
| Настройки | `/settings` | Профиль и оформление (тема) |
| Ачивки | `/achievements` | Выданные награды и каталог; в меню нет, вход с главной |

Меню имени в панели: только «Профиль» (ведёт в Настройки) и «Выйти».

«Проверка» в 5.0 не отдельный раздел, а вкладка «На проверке» внутри «Домашек»:
у учителя одна точка, где видно всё по домашкам.

## Сущности и связи

```
Ученик ──┐
         ├── Класс (один ученик или группа) ── Курс ── Уроки
Ученик ──┘        │
                  ├── Расписание (уроки класса по дням недели)
                  └── Домашки (на каждого ученика класса)
                          статус: задано → сдано (на проверке) → проверено (оценка, комментарий)
Ученик ── Ачивки (учитель выдаёт награду из каталога)
```

- Класс — главная единица, как в EdVibe: к нему привязаны курс, расписание и домашки.
- Домашка задаётся классу и раскладывается на каждого ученика класса.
- Счётчики на главной («На проверке», «Домашки», «Ачивки») и плашка в «Учениках»
  считаются из этих данных, а не прописаны вручную.

## Данные в макете

- `src/data/mock.ts` — неизменяемые справочники: ученики, курсы, классы, расписание.
- `src/data/store.ts` — то, что меняется по клику: домашки и выданные награды.
  Общий для всех страниц стор на `useSyncExternalStore`, живёт до перезагрузки.
  В настоящем приложении на его месте API с теми же формами данных.

## Код

- Версии переключаются в `UiPrefs` (`localStorage`), по умолчанию открывается 5.0.
- Страницы с отдельным видом для 5.0 выбирают вариант по версии:
  `Home → HomeV50`, `Courses → CoursesV50`, `Students → StudentsEdvibe`.
- Общие стили 4.8/5.0 — классы `ev-*` в `index.css`; стили только 5.0 — блок `/* --- 5.0 --- */`.
- Все модалки идут через `components/Modal.tsx`: портал в `.app-shell`, центр экрана,
  размытый фон, закрытие по Esc и клику мимо.

## Правила вида (чтобы не было «AI-слопа»)

- Без градиентных пятен, свечения, эмодзи в подписях и декоративных «блобов».
- Белые панели, одна акцентная полоска у карточки, плоские мягкие кнопки.
- Тексты короткие и по делу: «Проверить», «Задать домашку», «Сегодня уроков нет».
- Цвет класса один и тот же везде: карточка класса, урок в расписании, полоска на главной.
