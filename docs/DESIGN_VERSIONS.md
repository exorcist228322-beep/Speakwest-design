# UI version map

Все версии живут в одном коде. Переключатель в UI пишет `sw-version` в `localStorage` и ставит класс `version-vXX` на shell.

## База

- **v1** — классический header + sidebar, home со stats + ученики
- **v2** — фон `bg-edu-pattern.svg`, та же структура
- **v3** — icon rail (сворачивается/раскрывается по hover)
- **3.1 (`v31`)** — серая «пластина», eagle logo
- **3.2 (`v32`)** — без top header, профиль в rail, Students = graduation cap
- **3.3 / 3.4** — более яркие палитры на базе 3.2

## Home redesign (v4.x)

- **4.1** — activity strip + 6 белых `stat-card` в сетке 3×2
- **4.2** — soft `metric-tile` (цветные заливки, иконка справа сверху)
- **4.3** — белые `panel-v43` с цветной полоской слева + стрелки
- **4.4** — как 4.3 + welcome-баннер вместо обычного page-top
- **4.6** — campus: плашка активности с blobs + цветные campus-карточки 3×2
- **4.7** — пропорции/плашка как 4.6, стиль плиток как 4.2  
  (ачивки = `0`, настройки без стрелки/числа)
- **4.8** — как 4.7 (плашка, палитра), но карточки `panel-v43` из 4.4
  Разделы в порядке EdVibe: Главная, Классы, Ученики, Курсы, Расписание, Проверка, Настройки.  
  «Классы» (`Classes.tsx`): индивидуальные и групповые, цветные карточки с буквой, «Создать класс».  
  «Расписание» (`Schedule.tsx`): неделя 8:00–22:00, переключение недель, «Сегодня», линия текущего времени.  
- **5.0** — основная версия, все разделы рабочие: «Домашки» (проверка с оценкой, «Задать домашку»),
  «Ачивки», «Курсы» как «Материалы» EdVibe, новая главная без декоративной плашки. Подробно: `ARCHITECTURE.md`
  Меню имени: только «Профиль» (ведёт в Настройки) и «Выйти»; тема переехала в Настройки → Оформление.  
  «Ученики» как в EdVibe (`StudentsEdvibe.tsx`): поиск, фильтр, группы, плитка/список, сортировка, «Создать ученика», строки с кнопками.

- **5.1** — то, что сейчас на edu.speakwest.tech. Голубая палитра, шрифт Golos, плоские кнопки, узкое меню слева
  с именем (Профиль, Выйти), белые панели для разделов. Учитель: Главная, Ученики (и комната ученика), Курсы, урок,
  Домашки (На проверке / Задано / Проверено, экран проверки), Настройки (профиль и тема), живой урок.
  Ученик: Главная с уровнем и опытом, Курсы, урок, Домашка, Награды. Вход и выбор ученика: `/login`, `/choose`.
  Классов, расписания и ачивок от учителя тут нет: на проде их пока нет.
  Всё лежит в `src/v51/`: `v51.css` (стили только под `.v51`), `data.ts` (моковые данные), `ui.tsx` (рейл, панели,
  карточки, строки), `teacher/`, `student/`, `Lesson.tsx`, `Auth.tsx`. Новый экран: страница в `teacher/` или
  `student/` и строка маршрута в `App51.tsx`.
